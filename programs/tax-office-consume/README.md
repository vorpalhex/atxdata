# Tax Office published exports and delinquency snapshots

## CLI frontend contract

The source entrypoint is `bun /absolute/path/to/this/program/src/cli.ts COMMAND [OPTIONS]`; it does not depend on the caller's working directory. There is no newly installed binary. `--help`, `-h`, `help COMMAND`, and `COMMAND --help` / `COMMAND -h` are offline informational paths on stdout, status 0, without opening archive state. Plain invocation and missing input fail with usage on stderr, status 1; nothing prompts or consumes stdin. `--version` before the command reports the newly declared CLI/package identity 0.1.0, not an upstream release or data version. Package dependencies are unchanged.

All operational options are command-local and follow the command; there are no operational global options to move before it. Required values support both `--key=value` and `--key value`. Options may be reordered; repeated options, empty values, unknown names and arbitrary abbreviations are rejected rather than guessed. Only `-h` has a short spelling; grouped/attached short options are not supported. Recognized help bypasses unrelated parse failures, but a required value spelling `--help` is not help. A split value starting `--` is rejected as a missing value; use `--key=VALUE` for an option-like literal. `--` ends options in the command scope; these commands accept no file operands, so following operands are rejected without interpreting them as help. A trailing `--` alone is allowed. Bun 1.3.14 itself consumes a separator immediately after the script path: to deliver a top-level separator use `bun src/cli.ts -- -- TOKEN`; normally put the separator after a command, e.g. `bun src/cli.ts list -- --help` (an operand error, not help). This runtime-boundary limitation cannot be recovered from the argv delivered to the program.

Operational success remains exactly one JSON document with one newline on stdout, with the existing schema and no decoration, pagination or progress mixed into it. Help/version are plain text exceptions. Parser/domain failures remain status 1 on stderr without expected-error stacks; diagnostics identify option names without echoing values or arbitrary record-like operands. Retained source files are canonical regular files (ZIP inputs must be seekable), not stdin streams; `-` is not an archive input/output convention. `--output` names the existing private durable archive root, not a JSON destination. Redirect stdout normally for JSON. No new color, prompt, pager, quiet or framework controls are implied.

Checked stdout writes use bounded 16 KiB chunks, partial-write accounting and a ten-second EAGAIN deadline. EPIPE specifically from stdout delivery preserves the observed quiet status 0 early-consumer policy; domain EPIPE errors are not suppressed. Other output failures, including EBADF, now fail status 1 with a concise stderr diagnostic: this intentionally corrects prior false-success status 0 after lost JSON. No Bun source excerpts/stacks are emitted.

Completed checkpoint/archive work is not erased when result delivery fails; inspect status and verify before retrying. A delivered result does not itself certify every archived record's semantics. Pure frontend selection/budget/conflict checks run before Store/Collector opening, with library guards retained. Existing policy/history/locks are not reset or adopted. SIGINT uses native process termination (POSIX Python status -2, commonly shell status 130); a lock and interrupted/pending evidence can remain. Establish the writer is dead and review private evidence before any operator recovery; the CLI never auto-removes a stale lock. Local checkpoint cancellation is tested, not automatic remote resume or repeated-signal/remote-child cleanup guarantees.

The shipped `test/frontend.test.ts` invokes `test/frontend_native.py` (Python 3 stdlib) through the absolute Bun executable, from an unrelated private cwd with isolated HOME/XDG/TMPDIR and EOF. It checks independent stdout/stderr/status/state, all help paths, token context, equals/split forms, invalid/repeated/numeric/conflicting inputs, legacy JSON, real local catalog/import/verify/reuse, nonblocking slow-pipe large JSON, inherited read-only stdout (EBADF), closed-reader pipes and bounded SIGINT/lock refusal. Fixture directories and per-case receipts remain under explicitly supplied canonical TMPDIR outside checkouts, including on failure. Run all tests behind OS public-network denial; only existing authored loopback fixtures need a localhost exception. Standalone: `BUN=/absolute/path/to/bun python3 test/frontend_native.py`. Source entrypoint behavior is exercised on macOS arm64/Bun 1.3.14; Linux/Windows, installed binaries/uninstall, full mixed PTYs, exhaustive filename encodings/permissions and live remote cancellation remain unverified. No public acquisition is part of these regressions.

Tax `collect --version HASH` is still the retained-export selector; `--catalog-version HASH` still selects the retained catalog. They are not intercepted by top-level program version handling, in either equals or split form. Both are invalid for delinquency, and `--version HASH --refresh` conflicts; these fail before archive initialization. Bare `--refresh` remains supported by import/collect, with omission meaning false. `--refresh false` and `--refresh=false` are rejected, not converted into permission. Tax numeric options retain their positive decimal-digit safe-integer syntax (unlike TCAD Number notation).

Bun/TypeScript + SQLite, headless and read-only. The published property-data page supplies a retained, versioned catalog of actually linked CSV/XLSX/ZIP exports, dataset-specific layouts, and rates/exemptions/history pages. Select an exact catalog item ID, not a guessed historical filename. Generic acquisition retains complete raw originals with the explicit `raw-original` profile, `rows: null`, and `unsupportedFormat`: it does NOT claim that current/prior rolls, spreadsheets, ZIPs, or rates have been semantically decoded. The separate `delinquency` selection provides the existing exact 31-field semantic importer. No account search, record requests, scheduler, archive extraction, or TCAD crosswalk.

Prerequisites: Bun (installation: https://bun.sh/docs/installation) and Poppler `pdfinfo`/`pdftotext` on PATH for semantic delinquency. In this program directory, first run `bun install --frozen-lockfile --offline` against the existing cache; do not silently perform a network install on a cache miss. The examples below use operator-supplied canonical paths, not runnable placeholder source data.

Catalog and general acquisition (one private ARCHIVE, outside every checkout):

    bun src/cli.ts discover --output "$ARCHIVE" --max-requests 12 --max-total-bytes 16777216
    bun src/cli.ts list --output "$ARCHIVE"
    bun src/cli.ts collect --selection /voterdata/TaxCurOpenData.csv --output "$ARCHIVE" --max-bytes 536870912 --max-total-bytes 1073741824 --max-requests 12
    bun src/cli.ts collect --selection /voterdata/TaxCurOpenData.csv --output "$ARCHIVE" --refresh --max-bytes 536870912 --max-total-bytes 1073741824

The large current/prior-roll example requires separate authorization before execution; development did NOT download it. Use only item IDs returned by your retained catalog. `discover` is an explicit policy-checked refresh, while `list --output` is offline. Bare `list` preserves the legacy adapter description. `--catalog-version HASH` selects an exact retained discovery-body hash; a network refresh refuses a different current catalog. `--version HASH` selects an already retained export observation and never constructs a remote historical URL. Published label years are metadata, not daily snapshot publication dates. A file disappearing from a newer catalog does not invalidate an explicitly selected retained version. Conflicting cached/catalog bindings fail clearly rather than silently substituting another version.

Offline general import uses a retained source page and selected item binding:

    bun src/cli.ts catalog-import --html "$RETAINED_PROPERTY_HTML" --output "$ARCHIVE"
    bun src/cli.ts import-export --selection /voterdata/TaxCurOpenData.csv --file "$RETAINED_ROLL" --layout "$RETAINED_CURRENT_LAYOUT" --output "$ARCHIVE" --max-bytes 536870912

Paired layouts are derived from the published dataset/layout labels: current/prior exports do not use the delinquency layout. Missing required paired layouts fail; unrelated standalone catalog items do not acquire a forced layout. Raw layout bytes are retained without claiming schema interpretation. Catalog comments, foreign authorities, account-search links and credential-bearing URLs are excluded. Generic discovery is restricted to direct published export links and labeled rates/history/layout pages; it is not recursive website crawling or a claim of every Tax Office holding. Metadata may be discoverable even when a linked file is unavailable; acquisition preserves the actual HTTP failure rather than fabricating a file. A HTTP-200 HTML wrapper at a bulk-file link fails with a retained receipt.

General defaults: 512 MiB per raw artifact, 1 GiB conservatively accounted work bytes and 12 attempts per invocation. All byte/row/request/work controls accept positive finite safe integers through CLI and library; there is no hidden 4 MiB/50000-row product ceiling. `maxRows` does not imply raw semantic parsing: raw snapshots deliberately have no row count. Complete originals are streamed to private no-clobber files and hashed incrementally. Semantic delinquency records are decoded incrementally and persisted within a SQLite transaction, including complete-response row-limit rejection and rollback, never first-N success. Failed-run reservations are not reduced; a new explicit operation has its own work budget but shares the same durable source cooldown and history. Generic live continuation resumes only the same selection/binding/limits, verifies the retained data, rechecks policy/catalog and acquires missing artifacts. `--refresh` preserves abandoned/failed evidence and starts a new observation. Transfers restart whole files; there is no HTTP range-resume or reconstruction of mutable rolls from ranges.

Requires Bun and Poppler `pdfinfo` and `pdftotext` on PATH. From this program directory:

    bun install --frozen-lockfile --offline
    bun src/cli.ts list
    bun src/cli.ts import --selection delinquency --max-rows 10000 --csv "$RETAINED_CSV" --layout "$RETAINED_LAYOUT" --output "$ARCHIVE"
    bun src/cli.ts status --output "$ARCHIVE"
    bun src/cli.ts verify --output "$ARCHIVE"

`RETAINED_CSV`, `RETAINED_LAYOUT`, and `ARCHIVE` are non-resolving operator-supplied placeholders for canonical paths outside every checkout. ARCHIVE is the one private mode-0700 owned source archive root, containing ALL snapshots and cooldowns, not a new root per date. Never operate two archive roots for this source; the shared exclusive writer lock serializes this root only. Stale locks are not adopted or removed automatically: establish that the recorded PID is dead and inspect private evidence before operator removal.

An import validates both originals, records observations/runs/artifact hashes and original URLs, and preserves original strings and raw bytes privately. Identical reruns retain a separate reuse observation but do not claim a second distinct byte version. Missing layout cannot complete a CSV-only snapshot. Interrupted pending files remain private; a later import may reuse a validated artifact only when its hash matches the supplied original. Default retries resume only the same bytes. Explicit `--refresh` is supported by both import and collect: it marks incomplete checkpoints for that mode/bound abandoned, preserves their failed/interrupted runs and artifacts, and allocates a fresh snapshot for changed source bytes. It never rewrites a completed observation. Atomic hard-link/no-clobber promotion and the SQLite transaction finish the two-artifact checkpoint; pending/interrupted/failed artifacts are not successful snapshots. Unknown original retrieval/publication times remain NULL; import observation time is not original retrieval time. Filenames, HTTP Date/Last-Modified, and roll years are not publication dates.

Semantic delinquency network mode (bounded official-source integration exercised; see evidence below):

    bun src/cli.ts collect --selection delinquency --max-rows 10000 --output "$ARCHIVE"
    bun src/cli.ts collect --selection delinquency --max-rows 10000 --refresh --output "$ARCHIVE"

Default collect reuses a verified complete snapshot of the selected source/profile with zero HTTP. Explicit refresh rechecks robots and discovery before exact CSV/layout routes. Legacy delinquency defaults are eight attempts and 16 MiB conservatively reserved response bytes; its CSV default is 4 MiB, layout/discovery/robots 2 MiB each. Raise `--max-bytes`, `--max-rows`, `--max-requests` and `--max-total-bytes` explicitly as required. Shared transport retains up to three retries per route, a 60-second full-body timeout, at least 3-second completion-to-start pacing, jitter, and durable successful/error-response server cooldowns. Only the robots route may follow one HTTP 302 whose actual Location resolves exactly to the same-origin HTTPS `/404` allowlist entry, with no query, fragment or user information. The hop is a separate paced, budgeted request; another redirect is refused. A missing robots page requires HTTP 404 with empty/recognized missing text, or a recognized missing-page title AND body (HTTP 200 is allowed only on the approved `/404` hop). Arbitrary HTML, login/challenge pages and unsupported robots instructions fail closed. No cookies, credentials or challenge bypass; credentials are explicitly omitted. Ambiguous quotas, encoded bodies and real gates stop the run. A persisted ambiguous cooldown requires operator review, never automatic reset. Failed/interrupted attempt reservations are never reduced to zero.

Explicit positive safe-integer `--max-rows` remains mandatory for semantic delinquency; it bounds full-response parsing and never silently truncates. Retained import also accepts `--max-bytes`; larger compatible historical observations are supported without implying remotely published history exists. Accounts retain 14-character text IDs; exact header includes `Last Tax Roll Year ` with trailing space. BigInt decimal cents check every money field and balance equality. Blank/0000 first-delinquent years remain unknown, with original strings retained. PDF signature/footer and actual pdfinfo parsing are required; bounded pdftotext extraction (128 KiB text, five-second subprocess timeout) must match all 31 ordered field labels plus key account/balance/sequence/year/property meanings. Documented case/spacing/punctuation aliases and stale 2012 explanatory prose are tolerated, not treated as coverage. Unrelated valid PDFs and changed/unrecognized layouts fail at import and verify; application/octet-stream is documented and accepted.

Verification rehashes retained files, reparses the exact 31-field schema, recomputes row projections and snapshot hashes, checks source/selection/URL/run identity, and checks SQLite integrity/foreign keys. A completed or reused observation explicitly binds its successful terminal run, matching mode/limits, valid observation/start/finish chronology and NULL error. Interrupted/failed artifact-producing runs remain legitimate history when a later bound run completes the same-byte checkpoint. Legacy databases acquire this binding only when exactly one historical succeeded run identifies the completion; malformed or ambiguous histories fail closed rather than being silently blessed. It performs no HTTP. Full-response row count is not countywide holdings completeness; mutable paired downloads are not a server-side atomic tax ledger. Balances are not appraisal values.
