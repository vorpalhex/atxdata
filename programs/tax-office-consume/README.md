# Tax Office delinquency snapshots

Bun/TypeScript + SQLite, headless and read-only. Only the delinquency CSV and its PDF layout are supported. No account search, current/prior roll, Excel, rates, exemptions, scheduler, or TCAD crosswalk.

Requires Bun and Poppler `pdfinfo` and `pdftotext` on PATH. From this program directory:

    bun install --frozen-lockfile
    bun src/cli.ts list
    bun src/cli.ts import --selection delinquency --max-rows 10000 --csv "$RETAINED_CSV" --layout "$RETAINED_LAYOUT" --output "$ARCHIVE"
    bun src/cli.ts status --output "$ARCHIVE"
    bun src/cli.ts verify --output "$ARCHIVE"

`RETAINED_CSV`, `RETAINED_LAYOUT`, and `ARCHIVE` are non-resolving operator-supplied placeholders for canonical paths outside every checkout. ARCHIVE is the one private mode-0700 owned source archive root, containing ALL snapshots and cooldowns, not a new root per date. Never operate two archive roots for this source; the shared exclusive writer lock serializes this root only. Stale locks are not adopted or removed automatically: establish that the recorded PID is dead and inspect private evidence before operator removal.

An import validates both originals, records observations/runs/artifact hashes and original URLs, and preserves original strings and raw bytes privately. Identical reruns retain a separate reuse observation but do not claim a second distinct byte version. Missing layout cannot complete a CSV-only snapshot. Interrupted pending files remain private; a later import may reuse a validated artifact only when its hash matches the supplied original. Default retries resume only the same bytes. Explicit `--refresh` is supported by both import and collect: it marks incomplete checkpoints for that mode/bound abandoned, preserves their failed/interrupted runs and artifacts, and allocates a fresh snapshot for changed source bytes. It never rewrites a completed observation. Atomic hard-link/no-clobber promotion and the SQLite transaction finish the two-artifact checkpoint; pending/interrupted/failed artifacts are not successful snapshots. Unknown original retrieval/publication times remain NULL; import observation time is not original retrieval time. Filenames, HTTP Date/Last-Modified, and roll years are not publication dates.

Network mode (bounded official-source integration exercised; see evidence below):

    bun src/cli.ts collect --selection delinquency --max-rows 10000 --output "$ARCHIVE"
    bun src/cli.ts collect --selection delinquency --max-rows 10000 --refresh --output "$ARCHIVE"

Default collect reuses a verified complete snapshot with zero HTTP. Explicit refresh rechecks robots and discovery before exact CSV/layout routes. Every run has at most eight attempts and 16 MiB conservatively reserved response bytes; per-response CSV ceiling 4 MiB, layout/discovery/robots 2 MiB each, up to three retries per route, 60-second full-body timeout, 2-second completion-to-start pacing, jitter, and durable successful/error-response server cooldowns. Only the robots route may follow one HTTP 302 whose actual Location resolves exactly to the same-origin HTTPS `/404` allowlist entry, with no query, fragment or user information. The hop is a separate paced, budgeted request; another redirect is refused. A missing robots page requires HTTP 404 with empty/recognized missing text, or a recognized missing-page title AND body (HTTP 200 is allowed only on the approved `/404` hop). Arbitrary HTML, login/challenge pages and unsupported robots instructions fail closed. No cookies, credentials or challenge bypass; credentials are explicitly omitted. Ambiguous quotas, encoded bodies and real gates stop the run. A persisted ambiguous cooldown requires operator review, never automatic reset. Failed/interrupted attempt reservations are never reduced to zero.

Explicit `--max-rows` is mandatory (1–50000); it bounds full-response parsing and never silently truncates. Accounts retain 14-character text IDs; exact header includes `Last Tax Roll Year ` with trailing space. BigInt decimal cents check every money field and balance equality. Blank/0000 first-delinquent years remain unknown, with original strings retained. PDF signature/footer and actual pdfinfo parsing are required; bounded pdftotext extraction (128 KiB text, five-second subprocess timeout) must match all 31 ordered field labels plus key account/balance/sequence/year/property meanings. Documented case/spacing/punctuation aliases and stale 2012 explanatory prose are tolerated, not treated as coverage. Unrelated valid PDFs and changed/unrecognized layouts fail at import and verify; application/octet-stream is documented and accepted.

Verification rehashes retained files, reparses the exact 31-field schema, recomputes row projections and snapshot hashes, checks source/selection/URL/run identity, and checks SQLite integrity/foreign keys. A completed or reused observation explicitly binds its successful terminal run, matching mode/limits, valid observation/start/finish chronology and NULL error. Interrupted/failed artifact-producing runs remain legitimate history when a later bound run completes the same-byte checkpoint. Legacy databases acquire this binding only when exactly one historical succeeded run identifies the completion; malformed or ambiguous histories fail closed rather than being silently blessed. It performs no HTTP. Full-response row count is not countywide holdings completeness; mutable paired downloads are not a server-side atomic tax ledger. Balances are not appraisal values.
